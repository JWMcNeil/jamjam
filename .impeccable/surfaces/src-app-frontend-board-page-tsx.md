# /board

Hiring and curious visitors scan Jamie's photography and graphics. The stills lead; a scrap of context is optional in a modal. Success is remembering the pictures and that Jamie makes this too.

`/board` is the only sitemap URL. `/board/[slug]` restores the same modal over the masonry grid so a tile can be shared with its own Open Graph image. It is not a case study.

Structure: CSS-column masonry of intrinsic-ratio stills, quiet mono captions (`#photography` / title), Late-Night Terminal chrome. Empty: `ls: board/: no items`.
