# Board is not a Project

Non-web work (photography, video, graphics, music) was cut when the old Content collection died, then almost revived as more Projects. That would either restore two shops or force pictures into software-shaped case studies.

Board items live on `/board`, with context in a modal. `/board/[slug]` restores that modal for sharing and Open Graph; it is not a dedicated case-study page. Projects stay web/app case studies and the main feature. A hybrid job is two records, not a duplicate. Do not bring back Content vs Web collections.
